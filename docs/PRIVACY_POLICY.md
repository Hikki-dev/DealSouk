# DealSouk Privacy Policy Draft

Date: 2026-06-12
Status: Product/legal draft, not legal advice

## Plain English Summary

DealSouk helps shoppers compare grocery prices using community-submitted prices. We collect only what is needed to run the app: account details, neighbourhood-level shopping area, submitted prices, optional verification photos, requests, tokens, rewards, and moderation records.

Precise GPS is used only during the app session to show nearby supermarket prices. It must not be stored persistently.

Tokens are in-app rewards. They are not cash, cannot be transferred, and cannot be sold.

## Data We Collect

- Firebase account ID and login method.
- Phone number if phone login is used.
- Display name, language, and home area.
- Price submissions, timestamps, stores, products, and optional receipt or shelf-label photos.
- Request history, token history, badge/streak/leaderboard information, and voucher request status.
- Device messaging token for notifications.

## Data We Avoid

- Persistent precise GPS coordinates.
- Background location.
- Payment card details.
- Government identity documents.
- Photos unrelated to price verification.

## User Rights

Users can:

- Browse as a guest with limited features.
- Change display name, home area, and language.
- Deny location permission.
- Request account deletion.
