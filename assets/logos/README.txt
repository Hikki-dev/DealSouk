DealSouk — Supermarket Chain Logos
===================================

Drop the official chain logo image here using these EXACT filenames.
The app loads them as map pins and store-list avatars. If a file is
missing, the app safely falls back to a colored circle with the chain's
first letter, so nothing breaks.

Required filenames (lowercase, .png, ideally square ~256x256, transparent
background looks best):

  carrefour.png
  lulu.png
  spinneys.png
  waitrose.png
  union_coop.png
  choithrams.png
  geant.png
  nesto.png
  al_maya.png
  grandiose.png

Tips:
- Square PNGs with transparent backgrounds render cleanest in the circular pins.
- After adding/replacing files, run:  flutter pub get   then hot-restart.
- SVGs are not used here (kept simple with PNG); export logos to PNG first.
